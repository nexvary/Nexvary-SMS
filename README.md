# Nexvary SMS — Android

تطبيق شخصي بسيط لشركة Nexvary Inc يرسل SMS عبر Telnyx API V2. يتطلب Android 8 أو أحدث واتصال إنترنت؛ لا يحتاج صلاحية SMS أو جهات الاتصال.

## الاستخدام
1. ثبّت ملف APK من آخر تشغيل ناجح في Actions → Android APK and checks → Nexvary-SMS-1.0.0-APK. هذه نسخة اختبار موقعة بمفتاح debug وليست إصدار متجر.
2. أدخل مفتاح Telnyx في الهاتف فقط. يمكن حفظه اختياريًا مشفّرًا باستخدام Android Keystore (AES-GCM)، أو استخدامه في الذاكرة دون حفظ. لا ترسله في GitHub أو المحادثة.
3. أدخل رقم محمول مصري بصيغة +20 ثم 10 أرقام. تُحذف المسافات والأقواس والشرطات؛ يقبل التطبيق بادئات +2010 و+2011 و+2012 و+2015 فقط.
4. اكتب النص، ثم اضغط «مراجعة وإرسال رسالة واحدة». راجع المرسل والمستلم وعدد الأجزاء التقديري والتكلفة قبل التأكيد. لا يوجد إرسال جماعي أو إعادة تلقائية.
5. تُعرض الحالة ومعرّف الرسالة والتكلفة عندما ترجعها Telnyx. زر تحديث الحالة ينفّذ GET فقط. Accepted/Sent ليست Delivered؛ ظهور الاسم على الهاتف يؤكده المستلم.
6. بعد كل محاولة يُقفل الإرسال. للرسالة التالية استخدم زر «بدء رسالة جديدة». عند نتيجة غير مؤكدة، افحص سجل Telnyx أولًا قبل فك القفل؛ التطبيق لا يستطيع ضمان exactly-once على شبكة منقطعة.

الإعدادات المطابقة للسكربت: المرسل `Nexvary Inc`، ملف المراسلة `4001a1ea-906a-4085-b6a2-9188edac65b8`، الإرسال `POST https://api.telnyx.com/v2/messages`، والاستعلام `GET /v2/messages/{id}`. لا يوجد مفتاح API مضمن. التطبيق لا ينشئ Sender ID ولا يفعّل حساب Telnyx؛ يلزم استمرار موافقة مصر وصلاحيات الملف الحالي.

## التكلفة والأمان
- إرسال فعلي مدفوع بعد تأكيد محلي لكل رسالة. لا يتضمن التطبيق سعرًا ثابتًا؛ عدد الأجزاء تقديري والسعر الفعلي وفق حساب Telnyx وشبكة المستلم. النص العربي غالبًا UCS-2 ويستهلك أجزاء أكثر.
- لا يسجل التطبيق نص الرسالة أو المفتاح. يُحفظ محليًا آخر معرّف وحالة وتكلفة فقط لتفادي التكرار. النسخ الاحتياطي ولقطات الشاشة والاتصالات غير المشفرة معطلة. لا تحليلات أو إعلانات.
- حفظ المفتاح على الجهاز اختياري. Android Keystore ليس حماية من جهاز مخترق أو مستخدم فتح الجهاز. استخدم مفتاحًا محدود الصلاحيات متى أتاح الحساب ذلك. لا توزّع نسخة تتضمن مفتاحك؛ التوزيع العام يحتاج وسيطًا خلفيًا مصادقًا بدل أسرار شركة على أجهزة الآخرين.
- نسخة debug للتجربة الشخصية. مفتاح CI مؤقت؛ لا تعتمد توقيعه لتحديثات إنتاجية طويلة الأجل. قبل النشر العام يلزم إعداد مفتاح إصدار خاص ومستقر خارج المستودع.
- إغلاق/قتل عملية أندرويد قد يوقف الطلب؛ يُعامل الطلب الجاري كغير مؤكد عند إعادة الفتح ولا يعاد إرساله تلقائيًا. التطبيق ليس خدمة إرسال خلفية مستمرة.

## البناء والتحقق
JDK 17، Gradle 8.11.1، Android SDK 35، AGP 8.9.2:
```
gradle testDebugUnitTest lintDebug assembleDebug
```
تتحقق Actions من الاختبارات وlint وتوقيع APK ثم تحفظ APK والتقارير. اختبارات الوحدات تغطي التطبيع والبادئات ورفض المدخلات وعدّ أجزاء GSM/Unicode؛ ليست اختبار تسليم على هاتف حقيقي.
لا تُرسل CI أي رسالة ولا تحتاج مفتاح Telnyx. التراجع: إزالة التطبيق تحذف إعداداته ومفتاحه المحلي. لا يتغير حساب Telnyx أو FusionPBX أو AWS.
